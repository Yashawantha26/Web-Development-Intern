# 🍽️ HOYSALA RESTAURANT - Table Reservation System

A modern restaurant website built using **HTML5**. This project demonstrates a simple restaurant management interface where customers can explore the restaurant, view services, and reserve tables.

## 📖 About

HOYSALA RESTAURANT is a beginner-friendly HTML project designed to represent a restaurant's online presence. It focuses on providing a clean interface for customers to learn about the restaurant and request table reservations.

## ✨ Features

- 🏠 Home Page
- 🍴 Restaurant Information
- 📋 Menu Section
- 🪑 Table Reservation Section
- ⏰ Restaurant Opening Hours
- 📍 Contact Information
- 📱 Responsive Navigation
- 🎨 Clean and User-Friendly Layout

## 🛠️ Technologies Used

- HTML5

1. Clone this repository:
